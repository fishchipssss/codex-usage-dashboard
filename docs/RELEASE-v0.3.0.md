Windows portable desktop launcher: download **CodexUsageDashboard-Windows-x64.zip**, extract it and double-click **CodexUsageDashboard.exe**. No installed Python, Node.js, PowerShell command or open Codex app is needed. The dashboard opens in your default browser.

Windows 用户：下载 ZIP，解压后双击 EXE 即可。可以创建桌面快捷方式。

- Includes the existing community dashboard, local multi-profile accounting and redesigned UI.
- Reuses a compatible running service; never terminates unrelated port owners.
- Keeps Git metadata subprocesses windowless and decodes their output as UTF-8.
- Binds to 127.0.0.1:8765 and preserves existing local source configuration.
- Uses serial parsing in the frozen runtime. Closing the browser leaves the local server running; stop it in Task Manager if needed.
- Includes application, Python and PyInstaller license notices; no personal sessions, credentials, configuration or databases are included.
- Unsigned Windows x64 binary, built and smoke-tested by GitHub Actions. SHA-256 checksums are attached.

See [Windows instructions](https://github.com/fishchipssss/codex-usage-dashboard/blob/main/docs/WINDOWS.md) for usage, privacy and building from source. Original MIT copyright and upstream acknowledgement are preserved.
